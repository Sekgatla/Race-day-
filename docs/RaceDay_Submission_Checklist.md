# RaceDay Part 1 Submission Checklist

Use this checklist before submitting the repository link on ARC.

## Repository contents

- [ ] `README.md` is at the repository root.
- [ ] The seven-entity ERD PDF is in `docs/`.
- [ ] The editable ERD source is in `docs/`.
- [ ] The API endpoint plan is in `docs/`.
- [ ] The SQL Server database script is in `docs/`.
- [ ] The Harvard Anglia reference list is in `docs/`.
- [ ] `.github/workflows/part1-ci.yml` is in the repository.

## Evidence

- [ ] The SQL script has been executed successfully in SSMS.
- [ ] The database verification queries have been run.
- [ ] The GitHub Actions workflow has a green run.
- [ ] A screenshot of the successful workflow is linked in the README.
- [ ] The Part 1 video is uploaded as unlisted.
- [ ] The video link is included in the README.

## Quality checks

- [ ] The README describes Part 1 only and does not claim that Parts 2 or 3 are complete.
- [ ] The repository contains at least 20 genuine, meaningful commits.
- [ ] The repository is public and the final URL opens correctly.
- [ ] The ERD, API plan, SQL script, and references use the same entity and role names.
